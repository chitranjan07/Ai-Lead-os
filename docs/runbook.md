# Operator Runbook

1. Start MongoDB.
2. Copy `.env.example` to `.env`.
3. Run `npm run seed`.
4. Run `npm run dev`.
5. Open the frontend.
6. Select a lead and click Analyze.
7. Review the AI recommendation and draft.
8. Edit/reject/approve.
9. Email uses mock dry-run by default. Configure SMTP only for a controlled real-email test.
